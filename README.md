# 🛡️ Bilibili BulletFilter (BiliFliter)

B 站弹幕智能过滤 Chrome/Edge 扩展（MV3）。**100% 本地化、隐私优先**——弹幕数据不出本机，AI 走本地 [Ollama](https://ollama.com) 部署的模型。

## 功能

- **五层过滤链**：正则过滤 → 固定规则 → 本地屏蔽词 → 双阈值刷屏拦截 → AI 语义判断，层层过滤
- **本地屏蔽词**：完全本地确定性匹配（`includes`），毫秒级实时生效，不依赖 AI
- **屏蔽提示词**：一句话描述（如"屏蔽抽奖类弹幕"）注入 AI 提示词，语义级兜底
- **双阈值刷屏拦截**：刷屏词（哈哈/666/2333 等）第 3 条起拦；正常重复文本第 6 条起拦（30 秒窗口）
- **本地 Ollama 模型**：qwen3:4b 等，批量 3 + 并发 2，队列上限保护
- **查看过滤记录**：被过滤/已保留弹幕均可查看（各 200 条）
- **版本自检**：popup 顶部实时确认注入版本
- **统计恒等式**：已处理 = 已过滤（正则+固定+屏蔽词+刷屏+AI）= 已保留

## 工作原理

```
弹幕 DOM 节点插入 → 渲染前隐藏(preHide) → ① 正则 → ② 固定规则 → ③ 屏蔽词(本地 includes)
→ ④ 双阈值刷屏 → ⑤ AI 批量(异步) → 命中保持隐藏 / 通过恢复显示
```

### 过滤层说明

| 层 | 类型 | 示例 |
|---|---|---|
| ① 正则 | 本地确定性 | 排座党、打卡、单字符重复、纯符号 |
| ② 固定规则 | 本地确定性 | 一日游/到此一游/插眼 等打卡词分级 |
| ③ 屏蔽词 | 本地确定性 | 用户自定义（实时同步） |
| ④ 刷屏 | 本地确定性 | 哈哈/666/2333 归一化 + 30s 窗口计数 |
| ⑤ AI | 本地 Ollama | 屏蔽提示词语义判断（拿不准倾向保留） |

### 屏蔽词 vs 屏蔽提示词

- **屏蔽词**：精确、确定、毫秒级（`text.includes` 匹配）
- **屏蔽提示词**：AI 语义判断，覆盖变体（如"抽我""抽中我"），与屏蔽词互补

## 安装

1. `chrome://extensions` → 开启「开发者模式」
2. 「加载已解压的扩展程序」→ 选择本目录 `BiliFliter`
3. 安装 [Ollama](https://ollama.com) 并拉取模型：`ollama pull qwen3:4b`
4. 打开任意 B 站视频页 → 点击扩展图标配置屏蔽词/提示词

## 技术栈

- Manifest V3（Service Worker + content script）
- 本地 Ollama API（`http://localhost:11434`）
- 无任何外部依赖、无网络请求（弹幕数据完全本地处理）
